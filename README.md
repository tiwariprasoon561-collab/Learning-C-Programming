This repository contains basic C programs that I practiced while learning C programming.

|-----|--------|--------|
| 01 | Hello World | Basic Syntax |
| 02 | Even or Odd | If-Else |
| 03 | Minimum of Two Numbers | If-Else |
| 04 | Largest of Three Numbers | If-Else |
| 05 | Print 1 to 10 | Loops |
| 06 | Even & Odd in a Range | Loops |
| 07 | Multiplication Table | Loops |
| 08 | First & Last Digit (Modulo) | Operators |
| 09 | First & Last Digit (While Loop) | Loops |
| 10 | Check Prime Number | Loops + Logic |

## How to Run
You can run these programs on any C compiler like OnlineGDB, VS Code, CodeBlocks, etc.
